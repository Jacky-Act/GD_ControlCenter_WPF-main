# GD Control Center 帮助文档

欢迎使用 SCGD 机器控制软件。本文档将帮助您快速了解各个页面模块的功能与基本使用方法。

## 1. 仪表台

* **功能**：实时监控和手动操作核心硬件设备。
* **使用方法**：在此页面您可以查看当前硬件状态和光谱仪数据，并能手动下发控制指令，以及对光谱图进行保存。

### 硬件控制卡片

* **蠕动泵卡片**：控制蠕动泵的启停、方向和转速。
  * **用法**：点击卡片右侧的“启动/停止”按钮控制启停；点击左侧信息区域弹出参数设置窗口，可设定转速和运转方向（前向为向激发区域泵入液体），点击“应用”生效。
* **注射泵卡片**：控制注射泵的启停、方向和移动距离。
  * **用法**：点击卡片右侧的“启动”按钮启动注射泵。启动后将按照设定的移动距离，完成一次抽取和推出的操作。点击左侧信息区域可设定移动距离（0-3000对应0-4mL，距离越长抽取量越多）和移动方向（正向为向定量环内泵入液体），点击“应用”生效。
* **高压电源卡片**：控制高压电源启停，设置及实时监控电压、电流。
  * **用法**：点击卡片右侧的“启动/停止”按钮控制启停；点击左侧信息区域可设定目标电压（V）和电流（mA）值，点击“应用”生效。
* **转向阀门卡片**：与蠕动泵和注射泵联动，控制液体的流动路径。
  * **用法**：点击滑块切换状态。切换到“定量环”时，液体流经定量环到达激发区域；切换到“连续”时，液体不流经定量环，直接到达激发区域。
* **测样模式卡片**：选择“连续”或“小样”测量方式。
  * **用法**：选择“连续”模式时，样品直接到达等离子体，持续采集数据；选择“小样”模式时，系统将样品先泵入定量环，随后由背景溶液将其送入激发区域并进行测量（适用于样品量较少的情况）。
* **三维平台卡片**：控制三维平台的移动，用于调整等离子收光位置。
  * **用法**：点击卡片弹出窗口，选择轴向、正负方向和移动步长，点击“移动”按钮执行。“自动化校准”功能尚在开发中，暂不可用。
* **电池卡片**：实时监控系统电池电量及充电状态（该卡片仅供查看，不可点击）。
* **点火卡片**：用于进行等离子体的激发点火。
  * **用法**：在开启蠕动泵并确保液体在等离子区域稳定流动、且设定好合适的电压电流后，点击“点火”按钮进行激发。

### 光谱操作区域

光谱操作区域分为三个部分：设置参数与提示信息区域、光谱图表区域、操作按钮区域。

* **设置参数与提示信息区域**：
  * 点击“积分时间”或“平均次数”后的数值，可弹出窗口进行相应修改。
  * 提示信息区域会实时显示光谱仪的状态及故障信息。
  * **图表交互操作**：
    * 当未勾选“触屏框选”时：滚动鼠标滚轮可缩放图表；按住鼠标中键（滚轮）拖动可框选放大；双击鼠标中键恢复默认范围；按住左键可平移图表；按住右键可缩放；点击右键可以寻峰/取消寻峰。
    * 当勾选“触屏框选”时：支持按住鼠标左键直接框选放大，其余操作与上述一致。
* **光谱图表区域**：实时显示采集到的光谱曲线图。
* **操作按钮区域**：
  * **启动/停止光谱**：控制光谱仪采集的启停。
  * **打开文件**：读取并显示之前保存（单幅或脚本保存）的光谱图文件。
  * **单幅保存**：快速保存当前的一幅光谱图，保存路径可在“设置”页面中配置。
  * **脚本保存**：实现连续多次的光谱自动保存。点击后可设置“保存总次数”、“保存间隔”及“存储目录”，设置完毕后点击“启动保存”即开始批量记录。
  * **自动范围**：根据当前实时光谱强度自动调整纵轴范围，使波形铺满整个图表。
  * **最大范围**：将图表纵轴锁定在 0~70000 范围，便于在宏观尺度上观察信号强度的整体变化。

## 2. 时序图

* **功能**：实时绘制和观测光谱信号随时间变化的曲线。
* **使用方法**：
  1. 先在**仪表台**页面的光谱图表上进行寻峰操作。
  2. 切换到**时序图**页面，点击右上角的“采样配置”按钮。
  3. 在弹出的配置窗口中新建样品（或选择已有样品），并在“关联特征峰”的下拉框里选择刚才寻到的某一条特征峰线，点击“应用”。
  4. 最后点击“开始记录”按钮，即可开始绘制该特征峰的时序图。
* **补充说明**：
  * 时序图支持同时开启多条。
  * 当点击“停止记录”或在仪表台中去除寻峰线时，时序图会自动进行保存，保存的路径可在“设置”页面中进行配置。

## 3. 元素配置

* **功能**：管理测量时所需关注的化学元素及光谱波长信息。
* **使用方法**：
  1. 测试前，需要在此处添加或选择对应的元素特征波长。
  2. 配置该波长对应的测量积分时间和平均次数，并选择是“测量拟合曲线”还是使用已有的拟合曲线。
  3. 点击“加入分析配置”按钮，将待测元素的信息关联到后续的“样品序列”、“测样分析”和“数据处理”页面中，用于后续的测量操作。

## 4. 样品序列

* **功能**：编排自动化的样品测试队列，以及测量参数配置。
* **使用方法**：当需要测试样品时，在此处编辑样品信息列表。
  * **序列生成与配置**：点击“生成新序列”，系统会根据设定的“标准样品”数量、“待测样品”数量，以及“元素配置”页面选定的元素自动生成相应的序列。样品的名称和类型可编辑；标准样品需要输入浓度，浓度单位可通过“浓度单位”下拉框选择（ppm 或 ppb）。“重复次数”和“间隔”分别代表对该样品采集几次取平均值，以及每次采集之间的间隔时间。
  * **序列行操作**：选中某个序列行后，点击下方的“删除选中行”按钮可将其删除；点击“追加空白行”按钮可增加一行序列。
  * **应用与保存**：
    * 点击“应用当前序列至测量库”按钮，可将当前页面的序列配置下发到“测样分析”和“数据处理”页面。
    * 点击上方的“保存模板”按钮，可将当前的序列配置（包括元素配置）保存为用户模板。
    * 点击“打开文件夹”图标及对应的下拉框，可选择并应用已保存好的模板。

## 5. 测样分析

* **功能**：连续测量模式和小样品测量模式的执行与实时数据展示界面。
* **使用方法**：此页面会自动同步并加载在“元素配置”和“样品序列”中设定好的配置信息。
  * **界面布局说明**：
    * **左侧序列栏**：显示各序列的名称及其当前状态（如：未测量、测量中等）。
    * **实时全谱监控图表**：实时显示当前采集到的全谱图。
    * **测量强度趋势图表**：根据配置的“重复次数”，实时绘制每次测量的信号强度及波动趋势。
    * **右上角信息卡片**：展示当前正在测量的序列所对应的元素信息。
    * **右侧测量强度栏**：显示每一次具体的测量强度数值。当配置了多个元素时，可通过上方的“切换元素”下拉框切换查看不同元素的数据。
  * **测量操作**：
    * 点击“开始采集数据”按钮即可启动当前序列的测量。
    * 连续测量模式与小样测量模式在点击开始时，系统后台会采用各自不同的采集逻辑。
    * 当前序列的数据测量完成后，需由用户手动点击以继续进行下一个序列的测量。


## 6. 数据处理

* **功能**：对已经采集完成的数据进行拟合（空白与标准样品）与浓度计算（待测样品），并导出结果。
* **使用方法**：
  * **曲线拟合区域（左侧）**：
    * 通过上方的“元素”下拉框可切换查看不同元素的拟合曲线。
    * 核心图表区域用于显示拟合曲线，下方会同步显示该曲线的“拟合方程”、“相关系数”和“检出限”等实际数据指标。
    * 点击“更新拟合”按钮用于刷新图表；点击“保存曲线”按钮可将当前拟合好的曲线保存到对应波长的数据库中。
  * **数据展示区域（右侧）**：
    * **校准点数据**：以表格形式显示参与拟合的标准点及空白点的信息。
    * **待测样品分析结果**：展示待测样品的光谱测量数据，以及使用当前拟合曲线计算出的最终浓度结果。
  * **数据导出操作**：
    * 点击“导出报告”按钮，可将本次测量的分析结果导出为 PDF 报告文件。
    * 点击“导出详细数据”按钮，可同时导出上述的 PDF 报告，以及每个序列每一次测量的全光谱原始数据。
